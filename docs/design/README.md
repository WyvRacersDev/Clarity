# Clarity — Design Documents

The academic design artifacts produced while building Clarity as a
university project at **FAST-NUCES, Lahore** (Object-Oriented Analysis &
Design). Kept here as the project's record — the course was graded on the
analysis/design phases and on the correct application of **design patterns
and SOLID principles** (see the
[Design & Architecture](../../README.md#design--architecture) section of the
root README for where those landed in the final code).

> These documents capture the project as originally analysed and designed.
> Some details evolved during implementation — most notably persistence moved
> from "structured JSON objects, no database" to a **PostgreSQL** source of
> truth. The current architecture is described in the root
> [`README.md`](../../README.md).
