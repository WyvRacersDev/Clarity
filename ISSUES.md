| A13 | Med | Analytics **swallows load errors** (`ready=true` on the error path) → renders a blank/loading chart instead of an error state with retry. | `components/analytics/analytics.component.ts` | ✅ fixed (each data source now sets a `completionError`/`lineError` flag on the RxJS `error` path; the two fetches were extracted into retryable `loadCompletionData()`/`loadLineData()` loaders. | A14 | Med | SSR crash risks: unguarded `document`/`window` access (`document.createElement`, `document.querySelector`, `window.location.reload`). | `components/projects/project-detail/project-detail.component.ts`, `components/settings/settings.component.ts` | ✅ fixed (added `isPlatformBrowser` guards to the two `document.createElement` upload triggers and to settings' `window.location.reload`. These three components are also `RenderMode.Client`, so the guards are belt-and-suspenders) |
| A15 | Low | `listUsers` leaks the full user roster (every username, project count, last-modified) to any authenticated user. | `socket-server/src/realtime/user.gateway.ts` | ✅ fixed (no frontend feature consumes `listUsers`; the handler now SCOPES the response to the caller's OWN record via the JWT-first `identity()` resolver — anonymous sockets get an empty list. | A16 | Low | `joinProjectRoom` returns `success:true` for **nonexistent** projects; duplicate `saveProject` silently upserts with no "already exists" feedback. | collab / project gateways | ✅ fixed (part 1 was already closed by the A2 work — `joinProjectRoom` now runs through `authorizeEdit()`→`findProjectAuth()` and acks `{success:false, "Project not found"}` for a nonexistent project. Edits omit the flag and keep upserting) |
| A17 | Info | Backend runs **`AUTH_STRICT=true`** (rejects tokenless sockets), contradicting the "permissive by default" documented contract. Confirm intended mode. | `socket-server/src/config` | ✅ confirmed → permissive (set `.env` `AUTH_STRICT=false`). Intended mode is PERMISSIVE: the "Try the demo" entry point uses the legacy **tokenless** path (no JWT), so under strict its socket handshake would be rejected and demo mode would break. Matches the code/doc default; strict remains the future production target once the demo path also issues a token) |
